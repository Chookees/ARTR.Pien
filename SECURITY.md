# Security Policy

## Supported versions

Security fixes are applied to the latest published release on the `main` branch.

## Reporting a vulnerability

Please report suspected security issues privately. Do **not** open a public GitHub issue for vulnerabilities that could expose operators or scanned targets.

Include:

- Affected version / commit
- Reproduction steps against a local/loopback target you own
- Impact assessment
- Whether secrets, SSRF controls, or report redaction appear involved

We will acknowledge receipt and provide a remediation timeline when possible.

## Scope notes

Pien is a **passive verification** tool. Reports must never contain exploit payloads. Do not submit weaponized PoCs against third-party systems. Use only targets you are authorized to test.
